# 设计说明

## 系统组成

```text
本地图片 → 灰度/抖动转换 → 400×300 单色位图 → ESP32 Flash → SPI → 电子纸
                                          ↑
                                     BOOT 手动换页
```

图片以每像素 1 bit 存储，每帧 15,000 字节。数组放在 Flash；刷新时只把当前帧复制到 RAM。程序从第一张开始，自动轮播到末尾后回到开头；BOOT 低电平按下并做 30 ms 防抖，触发下一张。

## 为什么选择离线相册

- 图片数量有限且固定，适合直接打包进 Flash，结构简单。
- 不依赖家庭网络、账号、服务器或云端照片服务。
- 电子纸断电后保留最后画面，适合 USB 供电的桌面相框。
- 定时完整刷新减少刷新频次；屏幕刷新完成后进入休眠。

## 数据保护

仓库只含五张经允许公开的 400×300 点阵参考图。私人原图、个人照片目录、转换产生的固件数组、预览图、编译产物和固件二进制不随仓库发布。`.gitignore` 也排除了默认照片和本机生成文件。

## 文件导览

- `firmware/CoupleFrame/`：Arduino 主程序、轮播调度、按钮逻辑及 Waveshare 驱动。
- `tools/prepare_photos.py`：本地图片预处理和 C++ 数组生成。
- `assets/dot-matrix/`：屏幕分辨率的点阵演示素材。
- `tests/`：主机侧固件和图像转换检查。
- `enclosure/simple-frame/`：FreeCAD 建模源文件与打印格式导出件。
- `docs/hardware-and-assembly.md`：目标硬件、接线和烧录注意事项。
