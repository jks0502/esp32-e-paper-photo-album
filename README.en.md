# ESP32 E-Paper Photo Album

An offline photo frame for a 4.2-inch monochrome e-paper panel. It stores 400×300, 1-bit images in ESP32 flash, advances automatically about once a minute, and supports a BOOT-button next action. The repository includes Arduino firmware, an image preparation tool, hardware notes, and FreeCAD enclosure files.

**Privacy:** personal photographs are not included. The firmware image array is generated locally from the five permission-cleared, low-resolution dot-matrix references or your own local photos. Generated C++ arrays, local previews, and `/photos/` are ignored by Git.
