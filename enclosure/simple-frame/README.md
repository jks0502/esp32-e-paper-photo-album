# FreeCAD enclosure source and print exports

The enclosure source and exports in this directory are provided under CC BY 4.0. `build_case.py` creates the editable FreeCAD model and printable parts. The STL, STEP, and OBJ files are interchange exports.

The design targets a 4.2-inch, 400×300 panel. Its driver and adapter clearances are design envelopes, not measured guarantees. The recorded CAD checks report `physical_fit_verified: false`; measure your actual hardware and test-fit before printing a full set.
